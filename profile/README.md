# Project Overview

MobaXterm is an all-in-one remote computing and network toolbox for Windows. It combines a tabbed terminal, SSH client, X11 server, remote desktop tools, SFTP browser, network utilities, and Unix-like commands in a single application.

The software is designed for system administrators, developers, network engineers, IT professionals, and users who need to work with remote computers and servers.

MobaXterm supports multiple session types, including SSH, SFTP, FTP, RDP, VNC, Telnet, Mosh, XDMCP, and serial connections. It also provides integrated tools for file transfers, remote application display, SSH tunneling, and terminal automation.

---

# Terminal, SSH & Remote Sessions

MobaXterm provides a tabbed terminal environment based on a PuTTY-derived terminal engine. Users can open multiple sessions and organize them through the integrated session manager.

Supported session types include SSH, Telnet, Rlogin, RDP, VNC, XDMCP, FTP, SFTP, Mosh, and serial connections.

The session manager stores connection settings and provides quick access to frequently used remote systems. Multiple terminals can also be displayed using split-screen layouts.

The 2026 release adds commands such as `livesession` and `createsession`, allowing sessions to be launched or created from the local terminal or scripts.

---

# X11 Server & Remote Applications

MobaXterm includes an embedded X server based on X.org, allowing compatible graphical Unix and Linux applications to be displayed on a Windows desktop.

SSH X11 forwarding can be used to transport graphical applications through an SSH connection. The integrated X server supports OpenGL and other X11 extensions.

Users can also create XDMCP sessions for compatible remote desktop environments.

The embedded approach means users do not need to install a separate X server for supported MobaXterm workflows.

---

# SFTP, FTP & Remote File Management

When connecting to a server through SSH, MobaXterm can provide an integrated graphical SFTP browser.

Files can be transferred between the local computer and the remote server through the browser interface. Remote files can also be opened and edited using the integrated text editor.

MobaXterm supports both graphical and command-line file-management workflows, making it possible to combine terminal commands with visual file operations.

The 2026 releases also provide a right-click option for opening an SFTP session using the parameters of an existing SSH session.

---

# RDP, VNC & Network Tools

MobaXterm provides remote desktop connectivity through supported RDP and VNC sessions.

The 26.5 release added WebAuthn redirection support for RDP sessions, allowing compatible Windows Hello requests to be redirected to the local computer. VNC functionality was also updated with additional keyboard shortcuts, display-size adaptation, clipboard improvements, and additional encoding support.

The application also provides SSH gateways, port forwarding, network scanners, embedded services, and other tools for remote administration and network workflows.

---

# Unix Tools, Plugins & Automation

MobaXterm includes a collection of Unix-like command-line tools that can be used directly from its local terminal. Additional functionality can be installed through supported plugins.

Available tools include common commands such as Bash, grep, awk, sed, rsync, wget, and other utilities.

The MultiExec feature can send the same commands to multiple connected terminals, which can be useful for repetitive administrative operations.

Macros and command-line options can also be used to automate supported workflows.

# 2026 Updates

MobaXterm **26.5**, released September 11, 2026, includes several updates:

* WebAuthn redirection support for RDP sessions.
* Updated embedded Xorg server.
* Updated PuTTY-based terminal.
* Updated OpenSSL and OpenSSH components.
* Improved VNC keyboard shortcuts.
* Automatic VNC session resizing after remote resolution changes.
* Improved VNC copy and paste.
* Additional VNC encoding support.
* Improved handling of symbolic links and junctions.
* Various stability and security fixes.

Earlier 2026 releases added smart-card certificate authentication for SSH, smart-card management, CSV session import, RDM session import, session automation commands, paste-security warnings, and other improvements.

# System Compatibility & Performance

MobaXterm is designed primarily for Windows and is available in both installer and portable editions. The Home Edition can be used without installing additional frameworks or libraries.

| Component        | Minimum Practical Configuration     |
| ---------------- | ----------------------------------- |
| Operating System | Windows 10 / Windows 11             |
| Processor        | Modern dual-core CPU                |
| Memory           | 2 GB RAM minimum; 4 GB+ recommended |
| Storage          | 200 MB+ for application and plugins |
| Graphics         | Integrated graphics supported       |
| Display          | 1024×768 or higher                  |
| Architecture     | x86, x64, or supported ARM64 build  |
| Network          | Required for remote sessions        |
| X11              | Integrated X.org server             |

Actual resource usage depends on the number of open sessions, X11 applications, remote desktops, plugins, terminal tabs, and network activity.
